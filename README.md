# برنامجي الرياضي – تطبيق PWA لإدارة برنامج جيم لمدة 6 شهور

تطبيق ويب شخصي **ثنائي اللغة: العربية (RTL) والإنجليزية (LTR)** قابل للتثبيت على الهاتف، لإدارة برنامج تدريبي من **السبت 31 أكتوبر 2026** إلى **الجمعة 30 أبريل 2027** (26 أسبوعًا × 3 حصص = 78 حصة).

> **تنبيه:** التطبيق أداة لتنظيم التمرين وتسجيله. لا يشخّص أي حالة ولا يحدد سلامة أي تمرين طبيًا. التنبيهات الصحية تذكيرات عامة فقط.

## التصميم الجديد (Sport Dynamic)
- **لغتان**: العربية والإنجليزية من الإعدادات، وتتغير فورًا مع اتجاه الصفحة، وتتحفظ.
- **6 ثيمات** (Sport Dynamic، Premium Dark، Midnight Blue، Clean Light، Graphite Pro، Ocean Blue) مع معاينة لكل ثيم، و**وضع داكن / فاتح / حسب الموبايل** يعمل مع كل الثيمات (`src/lib/themes.ts`).
- **صور وفيديوهات لرجال فقط**: فيديو مدرب من قنوات يقدمها رجال (قائمة معتمدة في `src/data/videos.ts`، كل رابط اتأكد منه بـ oEmbed واتراجع غلافه)، وصور حقيقية من Wikimedia Commons، ورسومات واقعية من Everkinetic (CC BY-SA)، وصورتك أنت للجهاز. الفيديو بيشتغل بس لما تدوس عليه ومش بيتخزن على الموبايل. صفحة «المصادر» فيها المؤلف والرخصة لكل صورة.
- **البدائل**: زر «مش لاقي الجهاز؟ شوف البدائل» في كل تمرين، وبديلين على الأقل ببطاقات مصورة (الاسم، الفيديو، المعدات، العضلات، الصعوبة، المجموعات، الملاءمة الصحية، الأخطاء). الاختيار للحصة الحالية بس.
- **الأخطاء الشائعة** لكل تمرين: 3-5 أخطاء، لكل خطأ «ليه غلط» و«التصحيح»، مع الوضع والمدى الصحيح والتنفس.
- **مكتبة أجهزة** (54 جهازًا وأداة) بتصنيفات وبحث، ولكل جهاز: العضلات، طريقة الاستخدام، التمارين المرتبطة، الأخطاء، البدائل، السلامة، وهل هو متاح في جيمك.
- **إحماء مصوّر** مناسب للركبة والظهر بمؤقت لكل حركة وزر «تم الإحماء».
- **زر «تم – Complete»** يحفظ فورًا ويحدّث التقدم مع رسالة تحفيز متغيرة وزر تراجع، واحتفال في نهاية الحصة بالملخص.
- **اختيار من متعدد** بدل الكتابة: التوفر، الصعوبة، الألم، الطاقة، النوم.
- **الألم الشديد**: التطبيق يطلب إيقاف الحركة ولا يقترح بديلًا يحمّل نفس المنطقة في الحصة دي. ولا يقترح أبدًا تغيير أي دواء.

## ما يحتويه التطبيق

| الشاشة | المحتوى |
|---|---|
| **الرئيسية** | تاريخ اليوم، الحصة الحالية، زر بدء كبير، أيام التدريب، نسبة إكمال البرنامج، حصص الأسبوع، آخر وزن، ملخص آخر تمرين، تنبيه الحصص الفائتة مع إعادة جدولة يدوية أو تخطي |
| **تمرين اليوم** | معاينة الحصة (إحماء، تمارين، كارديو، تهدئة، سلامة) ثم وضع مباشر: الوزن والتكرارات و RPE لكل مجموعة، مؤقت راحة قابل للتعديل، بدائل، الألم والملاحظات، حفظ تلقائي بعد كل إدخال واستعادة بعد الإغلاق |
| **دليل الأجهزة** | 74 تمرينًا و54 جهازًا/أداة ببحث عربي/إنجليزي وتصفية حسب العضلة والمعدة، تفاصيل الضبط والأداء والأخطاء والتنفس والاحتياطات، روابط بحث، تمارين مخصصة (إضافة/تعديل/حذف) |
| **التقدم** | الوزن والقياسات، الالتزام الأسبوعي، تطور الأوزان والتكرارات والمجموعات، الكارديو، سجل الألم والتعافي، مقارنة الأسابيع والأشهر |
| **الإعدادات** | اللغة، الثيم ووضع العرض، بيانات المستخدم والحالة الصحية، تاريخ البداية وأيام التدريب، المعدات المتوفرة، النسخ الاحتياطي، روابط للبرنامج الكامل والسلامة |
| **التقارير** (من التقدم) | أسبوعي، شهري، شامل للستة أشهر، قابل للطباعة |

### البرنامج التدريبي
- 6 مراحل متدرجة (التأقلم ← الأساس ← القوة الأساسية ← التطوير ← البناء ← التثبيت والتقييم) مع أسابيع تخفيف (9، 18، 26).
- لكل أسبوع معاملات خاصة (مجموعات، تكرارات، RPE، راحة، دقائق كارديو، تركيز الأسبوع) – ملف `src/data/program.ts`.
- **لا زيادة تلقائية في الأوزان أو الحجم**: التطبيق يعرض قاعدة التقدم لكل مرحلة، والقرار للمستخدم حسب الأداء والتعافي واستجابة الركبة والظهر.
- التمارين التي لا تتوفر معلومات كافية لاعتبارها مناسبة (مثل Leg Extension، Hack Squat، Back Squat، Lunges، Romanian Deadlift، Back Extension، Cable Crunch، Rowing Machine) معلَّمة **"تحتاج مراجعة متخصص"** ولا تدخل البرنامج ولا تُقترح كبدائل.

### محرك البدائل (`src/lib/substitution.ts`)
يرتب البدائل حسب: (1) تشابه العضلات (جاكارد موزون) والحركة، (2) توفر المعدات من الإعدادات، (3) ملاءمة المستوى، (4) التوافق مع القيود الصحية المسجلة.
إذا كانت الملاءمة غير واضحة يُطلب تأكيد صريح. الاختيار يغيّر الحصة الحالية فقط ويحتفظ بالتمرين الأصلي في البرنامج.

### الصور والفيديو
ترتيب عرض الصورة لكل تمرين (`src/lib/media.ts`): صورتك أنت ← صورة حقيقية مدمجة (Wikimedia) ← رسم واقعي (Everkinetic) ← غلاف فيديو المدرب (مع الإنترنت فقط) ← مكان فارغ واضح مع روابط بحث.
- **لم يُخترع أي رابط فيديو.** كل فيديو اتأكد إن القناة صاحبته من القائمة المعتمدة (مقدموها رجال) وإن الغلاف لراجل بيعمل نفس التمرين. تاريخ آخر تحقق في `VIDEO_VERIFIED_ON`.
- تمارين من غير فيديو موثق لسه (زي الدراجة، الإليبتيكال، Band Pull-Apart) بتعرض الصورة والخطوات ورسالة «لا يوجد فيديو موثق بعد».
- الصور المدمجة صغيرة وبتتخزن للعمل بدون إنترنت؛ الفيديوهات لا.

### البيانات
- كل البيانات محفوظة **محليًا** في IndexedDB على هذا الجهاز وهذا المتصفح. **لا يوجد حساب ولا خادم ولا مزامنة سحابية.**
- تصدير نسخة كاملة JSON، وتصدير CSV لسجل التمارين والقياسات، واستيراد (دمج لا يحذف شيئًا، أو استبدال بعد تأكيد).
- كل حصة مسجلة تحفظ نسخة ثابتة من خطتها؛ تعديل البرنامج لاحقًا لا يغير السجلات القديمة.
- البيانات الافتراضية الوحيدة هي ما أدخلته في الطلب (الوزن 132.4، الطول 179، الحالة الصحية...)، ولا توجد سجلات وهمية.

## التشغيل محليًا

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev          # وضع التطوير: http://localhost:3000 (بدون Service Worker)
```

بناء النسخة النهائية وتجربتها (مع العمل دون اتصال):

```bash
npm run build        # يبني إلى مجلد out/ ويولّد out/sw.js
npm start            # خادم ثابت على http://localhost:3000
```

## الاختبارات

```bash
npm run lint         # فحص الأنواع TypeScript
npm test             # اختبارات الوحدة (Vitest): التواريخ، البرنامج، الجدول، البدائل، الحفظ والاستعادة، النسخ الاحتياطي
npm run build && npm run test:e2e   # اختبارات Playwright على شاشة 412×891 (قريبة من S25 Ultra)
```

اختبارات E2E تغطي: التنقل بين كل الشاشات، اتجاه RTL، عدم وجود تمرير أفقي، الحصص الفائتة وإعادة الجدولة، التمرين المباشر والحفظ التلقائي والاستعادة بعد التحديث، البدائل و"الجهاز غير موجود"، مؤقت الراحة، إضافة/تعديل/حذف التمارين، الدليل والبحث، التمارين المخصصة، القياسات، الوضع الداكن، تصدير واستيراد النسخة الاحتياطية، التقارير، والعمل دون اتصال عبر Service Worker.

## التثبيت على الهاتف (Samsung / Android)

يتطلب التثبيت أن يُفتح التطبيق عبر **HTTPS** (أو localhost).

1. انشر التطبيق (انظر القسم التالي) وافتح الرابط في **Chrome** أو **Samsung Internet**.
2. Chrome: القائمة ⋮ ← **تثبيت التطبيق** / **إضافة إلى الشاشة الرئيسية**. Samsung Internet: القائمة ← **إضافة صفحة إلى** ← **الشاشة الرئيسية**.
3. افتح التطبيق مرة واحدة مع اتصال بالإنترنت حتى تُخزَّن الصفحات؛ بعدها يعمل دون اتصال.

> مهم: بيانات التطبيق مرتبطة بالمتصفح والرابط. حذف بيانات المتصفح أو إلغاء تثبيت التطبيق قد يحذفها – صدّر نسخة احتياطية بانتظام.

## النشر

الناتج موقع ثابت بالكامل في مجلد `out/`، يمكن رفعه على أي استضافة ثابتة تدعم HTTPS:

- **Netlify:** أمر البناء `npm run build`، مجلد النشر `out`.
- **Vercel:** Framework: Next.js، أو Output Directory = `out` مع أمر `npm run build`.
- **Cloudflare Pages:** Build command `npm run build`، Output `out`.
- **GitHub Pages:** يعمل إذا نُشر على نطاق رئيسي (المسارات مطلقة من `/`). للنشر تحت مسار فرعي يلزم ضبط `basePath` في `next.config.ts` وتعديل المسارات في `manifest.webmanifest` و `sw.js`.

يجب أن يُخدَّم `sw.js` بدون تخزين طويل (`Cache-Control: no-cache`) حتى تصل التحديثات.

## هيكل المشروع

```
src/
  app/                 الشاشات (App Router، تصدير ثابت)
  components/          مكونات الواجهة (المؤقت، البدائل، الصور، الرسوم...)
  data/exercises.ts    مكتبة التمارين (بيانات منظمة)
  data/program.ts      مراحل البرنامج وقوالب الحصص ومعاملات كل أسبوع
  data/content/        المحتوى ثنائي اللغة لكل تمرين (الخطوات، الأخطاء، التنفس)
  data/equipment.ts    مكتبة الأجهزة والتصنيفات
  data/warmup.ts       حركات الإحماء المصوّر
  data/videos.ts       فيديوهات المدربين الموثقة
  data/photos.ts       الصور الحقيقية والرسومات مع المؤلف والرخصة
  lib/themes.ts        الثيمات الستة والوضع الداكن/الفاتح
  lib/i18n.tsx         اللغتين والاتجاه
  lib/                 قاعدة البيانات، الجدول، البدائل، الإحصائيات، النسخ الاحتياطي، التنبيهات الصحية
scripts/               توليد Service Worker والأيقونات وخادم ثابت
tests/                 اختبارات الوحدة و E2E
```

## حدود معروفة
- بعض التمارين وحركات الإحماء لسه من غير فيديو موثق، وبعضها من غير صورة حقيقية (بتظهر بالخطوات وروابط البحث).
- محتوى الفيديو اتراجع من القناة والغلاف، مش بمشاهدة كل ثانية فيه.
- لا مزامنة بين الأجهزة؛ الانتقال لجهاز آخر يتم بالتصدير ثم الاستيراد.
- روابط البحث والصور من روابط خارجية تتطلب اتصالًا بالإنترنت.
- محتوى التعليمات الفنية إرشادات عامة للتعلم وليس بديلًا عن مدرب أو أخصائي.
